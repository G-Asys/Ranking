# Ranking de Colocación

Tablero web de rankings de colocación por sponsor (BNCR, BCR, COOPENAE, Coope Ande, Banco Popular, Purdy).

- `index.html`: la aplicación completa (un solo archivo, sin servidor).
- Los datos se cargan con **⬆ Importar datos** (CSV o Excel de la hoja "Ventas 2025-2026") y se guardan en el navegador de cada usuario.

## Publicación

El sitio se sirve con GitHub Pages desde la raíz del repositorio.
